## Dataset produced

:::caution Corrected against the actual file
The dataset bundled and loaded by the dashboard, `Limpopo_Risk_Jan25_Jan26_Safe.csv`, is **58,085
records across all 9 South African provinces** — not the 7,384-record Limpopo-only figure this
section originally cited. A genuinely Limpopo-only 7,385-record file exists alongside it in the repo
but is never loaded by any script. See [Datasets →](/docs/data/datasets) for the full reconciliation.
:::

- **58,085 records** across all 9 South African provinces, 4,468 wards
- **13 monthly snapshots** (Jan 2025 – Jan 2026)
- 13 columns, drawn from the bundled CSV — not regenerated by `eo-datapipeline`, which runs
  separately and writes to PostgreSQL instead

[View dataset documentation →](/docs/data/datasets)
